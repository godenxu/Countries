# 寰宇 ATLAS · 世界国家信息大全 — 方案与路线图

## 已确认的关键决策

| # | 决策 | 结论 |
|---|---|---|
| 1 | 疆域口径 | **一个中国口径**：大陆 + 台湾(158) + 香港(344) + 澳门(446) 合并为单一实体 CHN，同色同轮廓、共用一份档案；港澳台在中国页面内作为"组成部分"列出，不进入国家列表与排行榜；叠加南海断续线（示意）。藏南 / 阿克赛钦暂按 Natural Earth 实控线，在"来源"页如实标注。 |
| 2 | 地图形态 | **3D 地球仪为主**，双击/按钮可连续摊平为等积平面图（Equal Earth）。球面与平面是同一份几何在顶点着色器里的形变插值，非双引擎。 |
| 3 | 交付形态 | 单文件 `index.html` + `manifest.json` + `sw.js` + 图标（PWA 安装与离线最稳）。 |
| 4 | 数据策略 | 内置离线基线 + 用户端联网自动刷新（World Bank / REST Countries，用户设备不受构建环境网络策略限制）。 |
| 5 | 语言 | 中英双语可切换，**默认中文**。 |
| 6 | 交付方式 | **不提交 git**；每个版本打包 zip，版本号为 UTC+8 时间戳（无分隔符，YYYYMMDDHHMMSS），并在界面左下角显示。 |
| 7 | 精编范围 | 首批 60 国精编长文，最终覆盖全部国家。 |

## 技术架构

- **渲染**：自研 WebGL2（不引 three.js）。land 网格 + 实例化线段 + 实例化贴地标签 + 云层 / 极光壳 + 双层大气 + 全屏星空 + 三级泛光后期。
- **贴地标签**：运行时把国名画进 2048×1024 字形图集，每个标签是一块切平面四边形（东向 × 北向基向量随形变插值），因此文字随地球旋转、透视收缩，且在泛光采样之后绘制以保持锐利。
- **几何**：Natural Earth 1:50m 拓扑（弧段 delta + zigzag varint + gzip，约 176 KB），运行时 earcut 三角化 + 4° 网格切分（约 20 万三角形），首帧前一次性构建（~0.3 s）。
- **投影形变**：`mix(spherePos, equalEarth)`，按与视图中心经度差做延迟展开，产生"从中心向两侧摊开"的效果。
- **拾取**：GPU picking（国家 ID 编码为颜色，半分辨率离屏 FBO，1×1 readPixels）。
- **昼夜**：按真实 UTC 计算太阳直射点（含均时差），球面模式全强度，平面模式衰减 72%。
- **自适应画质**：连续 45 帧中位帧时 > 34 ms 时自动关闭泛光并降到 DPR 1。

## 数据来源

- 疆域：Natural Earth 1:50m（公有领域），经 `world-atlas` 转换
- 国名 / 代码 / 货币 / 语言 / 邻国：`world-countries`（ODbL），中文名取自其 zho 译名
- 政体 / 宗教 / 国菜 / 国家象征 / 预期寿命 / 海岸线 / 海拔 / 年均温：`country-json`
- 人口：2024 年估算基线（`build/lib/curated.mjs`），中文首都名为人工整理
